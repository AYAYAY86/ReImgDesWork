Intro

This is a simple blog webpage for the workshop at the Hack the Promise Festival. Using the p5.js library, I created a collection of interactive widgets that let you experiment with code in a small playground and explore new ways of interacting. Let’s reimagine design tools together!

    Other Libraries

    A collection of other libraries that could also be interesting to explore and combine with p5.js.

    • hydra video synthesizer

      • Hydra is a browser-based, open-source live-coding video synth (created by Olivia Jack) that lets you write short JavaScript-like expressions to generate, chain, and mix real-time visuals (compiled to WebGL), suitable for experiments, performance and collaboration.

    • p5 live

      • p5.live (created by Ted Davis) is a browser-based environment for live-coding with p5.js, designed for performance, teaching, and experimentation.

    • p5 and hydra hy5

      • HY5LIVE (created by Ted Davis) is a minimal live-coding editor to showcase HY5 which bridges the gap between hydra-synth and p5.js, containing a suite of functions for passing visuals between both frameworks (hydra » p5 || p5 » hydra), while enabling global-mode code within both!

    • p5.js Learn

      • Screamer, which is a declarative language designed for ray marching visuals — you type code and immediately see 3D procedural graphics generated in real time.

    • ml5js

      • ml5.js is a high-level JavaScript library for machine learning built on top of TensorFlow.js, designed to make ML accessible to artists, designers, and creative coders.
